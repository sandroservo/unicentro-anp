# ADR-003 — RBAC com permissões resolvidas no JWT

**Status:** aceito · **Contexto:** 6 roles fixas, permissões majoritariamente estáticas.
**Decisão:** Role/Permission no DB, mas resolver permissões no login e carregar no token. `requirePermission()` no server.
**Consequências:** middleware edge-safe, zero query por request. Mudança de role só reflete no próximo login (aceito).
