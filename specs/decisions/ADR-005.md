# ADR-005 — OmniRoute como gateway de IA (Fase 2/3)

**Status:** aceito (supersede OpenRouter-direto) · **Contexto:** correção e tutor precisam de LLM; queremos um endpoint OpenAI-compatible com fallback entre provedores.

**Decisão:** OmniRoute (`lib/ai/openrouter.ts`) como gateway preferencial. Resolução de config: settings admin (`ai_base_*`) → env `OMNIROUTE_*` → legado OpenRouter. Sem chave no OpenRouter público → `NO_API_KEY` (503 / degrada com fontes RAG). OmniRoute local pode operar sem chave se `REQUIRE_API_KEY=false`.

**Consequências:** um wire para chat/correção; modelo `auto` roteia provedores; degrade gracioso; admin configura em `/admin/configuracoes`.
