# ADR-004 — pgvector + embeddings hash (dev)

**Status:** aceito · **Contexto:** RAG precisa de busca vetorial; ambiente dev sem chave de embeddings.
**Decisão:** Postgres pgvector (coluna vector(384) via SQL raw); embeddings determinísticos por hashing (dev).
**Consequências:** funciona sem API. Vetor inline no SQL (param+::vector zera resultado). Sem ivfflat com poucos dados. Trocar por embeddings reais depois.
