# ADR-001 — Evolução incremental sobre o MVP

**Status:** aceito · **Contexto:** MVP funcional (Next 14, next-auth v4). PRD v2 pedia plataforma completa.
**Decisão:** evoluir incrementalmente (preservar domínio/dados), migrando o framework na fundação — não greenfield.
**Consequências:** reaproveita auth/schema/AI; migração de stack isolada; menos retrabalho.
